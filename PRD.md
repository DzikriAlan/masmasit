Build a **professional, modern, premium web platform for Indonesian IT professionals**.

The core idea is:

> **One ecosystem for Indonesian IT resources, opportunities, knowledge, talent, and professional growth.**

This is NOT simply a job board and NOT simply an online community. It should become a **central platform where Indonesian IT practitioners can discover resources, opportunities, people, learning materials, projects, events, and professional services in one place.**

## Product Vision

Create a platform that feels like a serious Indonesian technology ecosystem, not a generic startup landing page.

Target users:

* Software Engineers
* Frontend / Backend Developers
* Fullstack Developers
* Mobile Developers
* DevOps / Cloud Engineers
* Data Engineers
* Data Scientists
* AI Engineers
* UI/UX Designers
* Product Managers
* QA Engineers
* Cybersecurity professionals
* IT students / juniors
* Tech founders
* Companies looking for IT talent

The product should feel credible enough that an experienced senior engineer would actually want to use it.

---

# Design Direction

The UI must be:

* Professional
* Modern
* Premium
* Minimal
* Clean
* Highly usable
* Contemporary
* Tech-focused
* Trustworthy
* Designed for Indonesian users
* Responsive
* Information-dense without feeling cluttered

### IMPORTANT: Avoid AI Slop

Do NOT create a typical AI-generated SaaS interface.

Avoid:

* Excessive gradients
* Giant glowing blobs
* Random purple/blue gradients
* Excessive glassmorphism
* Floating abstract shapes everywhere
* Generic "Empower your journey" copy
* Excessive rounded cards
* Every section inside a card
* Fake statistics
* Fake testimonials
* Stock-looking illustrations
* Generic dashboard screenshots
* Excessive animations
* Huge empty hero sections
* Repetitive cards with identical visual treatment

The design should look like it was created by an experienced product designer.

Think:
**Linear + Vercel + modern professional community/product platform**, but adapted specifically for the Indonesian IT ecosystem.

Use strong typography, spacing, hierarchy, subtle borders, restrained colors, excellent information architecture, and purposeful interaction.

# Visual System

Use a sophisticated design system.

### Typography

Use a modern sans-serif typeface.

Strong hierarchy:

* Display
* H1
* H2
* H3
* Body
* Caption
* Metadata

Typography should carry much of the visual identity.

### Color

Use a restrained palette.

Prefer:

* Neutral foundation
* One strong primary brand color
* Minimal accent colors
* Semantic colors only where necessary

Do NOT use the typical AI purple gradient aesthetic.

### Components

Build reusable:

* Buttons
* Inputs
* Search
* Tabs
* Filters
* Badges
* Cards
* Tables
* Avatars
* Dropdowns
* Modals
* Navigation
* Toasts
* Empty states
* Loading states

Use subtle borders and shadows.

Do not make every component heavily rounded.

# Most Important Requirement

Do NOT interpret this brief as:

"Make me a beautiful SaaS landing page."

Interpret it as:

**"Design and build the first serious digital ecosystem for Indonesian IT professionals."**

The product should feel like a platform people could actually use every day.

The visual quality should be closer to a mature technology product than a template marketplace theme.

Prioritize **product thinking, information architecture, usability, hierarchy, and credibility over decorative visuals.**

Make every section earn its place.

Avoid anything that looks obviously generated by an AI UI generator.
